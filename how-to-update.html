How to update

更新ガイド

専門知識は不要です。「写真を入れる」＋「JSONに1件書く」だけ。

0. はじめに（まず読む）

このサイトは 「写真を入れる」＋「JSONファイルに1件書き足す」だけで更新できます。HTML・CSS・JavaScriptは触らないでください。

  1. 画像を所定のフォルダに入れる
  2. data フォルダのJSONファイルに1件書き足す
  3. サーバーにFTPでアップロードする（変更したファイルだけでOK）
  4. サイトを開き、反映を確認する（反映されないときはブラウザを再読み込み）
JSONの注意点
① 文字は必ず半角の " で囲む　② 項目の間は ,（カンマ）で区切る　③ 最後の項目の後ろにカンマを付けない　④ 全体を [ と ] で囲む。間違えるとそのページが「データを読み込めませんでした」と表示されます。書いたあとに jsonlint.com などのJSON検証サイトに貼ると間違いを探せます。メモ帳でもOKですが、文字コードは UTF-8 で保存してください。

1件追加する基本のやり方：最後の } の後ろに , を付け、新しい { ... } を書き足します。

[
  { "title": "既存の1件目", ... },
  { "title": "新しく追加する1件", ... }
]

画像のルール

  • ファイル名は半角英数字とハイフン（例：gymkhana01.jpg）。日本語・スペースは使わない。
  • JPG形式、長辺1600px前後、1枚あたり500KB以下が目安（スマホの写真は縮小してから）。
  • JSONの "image" には、置いた場所とファイル名をそのまま書く（例：images/album/gymkhana01.jpg）。大文字小文字も一致させる。
  • 画像が見つからないときは「NO IMAGE」の代替画像が表示されます。

1. 部員を追加する

① 顔写真を images/members/ に入れる　② data/members.json に1件追記する。

{
  "name": "小島 オーシャン 和暉",
  "grade": "3年",
  "role": "Web運営",
  "car": "R53 MINI",
  "image": "images/members/小島オーシャン和暉.jpg",
  "comment": "ジムカーナ担当"
}

卒業した部員は、その1件を削除します（前後のカンマに注意）。

2. 部車を追加する

① 車の写真を images/cars/ に入れる　② data/cars.json に1件追記する。

{
  "name": "Mazda Roadster",
  "nickname": "ND",
  "year": "2018",
  "category": "Gymkhana",
  "image": "images/cars/roadster.jpg",
  "description": "練習用車両"
}

3. 活動を追加する

① 写真を images/activities/ に入れる　② data/activities.json に1件追記する。日付は YYYY-MM-DD（半角）。

{
  "title": "春の新歓走行会",
  "date": "2027-04-15",
  "category": "Event",
  "image": "images/activities/shinkan.jpg",
  "description": "新入生向け体験走行会"
}
今日より先の日付で登録すると、Schedules（活動予定）に自動で表示されます。トップページには日付の新しい順に3件が表示されます。

4. News（ブログ記事）を追加する

① 写真を images/news/記事ID/ に入れる　② data/news.json に1件追記する。一覧・記事ページ・トップのNews・検索・タグ・前後の記事・関連記事はすべて自動で作られます。

{
  "id": "2026-all-japan-gymkhana",
  "title": "全日本ジムカーナ参戦記",
  "date": "2026-11-20",
  "category": "大会結果",
  "tags": ["ジムカーナ", "全日本"],
  "thumbnail": "images/news/2026-all-japan/thumb.jpg",
  "images": [
    "images/news/2026-all-japan/1.jpg",
    { "src": "images/news/2026-all-japan/2.jpg", "caption": "スタート前" }
  ],
  "content": [
    "1つ目の段落です。",
    "## 見出し",
    "2つ目の段落。**太字** や [リンク](https://example.com) も書けます。"
  ]
}
id必須。記事のURLになる名前。半角英数字と - のみ。他の記事と重複不可。公開後は変えない
title / date題名 / 投稿日（YYYY-MM-DD）
category日本語でそのまま（例：大会結果・イベント・お知らせ）。新しい名前を書けばカテゴリーが自動で増えます
tagsタグの一覧。# は不要。クリックで同じタグの記事一覧へ
thumbnail一覧に出る画像（省略すると images の1枚目）
images本文の下に並ぶ写真（クリックで拡大）。文字だけでも、{"src","caption"} でも可
content本文。[ "段落1", "段落2" ] のように段落ごとに分けて書くと楽です
任意"important": true（重要ラベル）／"featured": true（トップの注目記事）／"galleryId"（ギャラリーへのリンク）／"description"（検索結果の説明文）／"draft": true（非公開）

本文の書き方（content）

## 見出し見出し（### で小見出し）
- 項目箇条書き（1. 項目 で番号付き）
> 文章引用（コメントなど）
**文字**太字
[文字](URL)リンク
![説明](images/…jpg)本文の途中に画像

親子記事（大会 → Day1・Day2・決勝 など）

まず親記事を書き、子記事に "parentId": "親のid" を付けるだけです。子記事の category・thumbnail は省略すると親のものを使います。並び順は "order": 1 などで指定できます（省略時は日付順）。

{ "id": "2026-all-japan", "type": "parent", "title": "2026全日本ジムカーナ", "date": "2026-11-20", "category": "大会結果", "content": "大会のまとめ" },
{ "id": "2026-all-japan-day1", "parentId": "2026-all-japan", "title": "Day1", "date": "2026-11-18", "order": 1, "content": "..." },
{ "id": "2026-all-japan-day2", "parentId": "2026-all-japan", "title": "Day2", "date": "2026-11-19", "order": 2, "content": "..." }

親記事のページには「子記事一覧」、子記事のページには親記事と兄弟記事のナビが自動で表示されます。子記事の下にさらに子記事を作ることもできます。

5. ギャラリー（イベントごとの写真）を追加する

① 写真を images/gallery/イベントID/ に入れる　② data/gallery.json にイベント1件を追記する。

A. 写真に連番を付けた場合（おすすめ・大量の写真向き）

写真のファイル名を 1.jpg、2.jpg…42.jpg にしておけば、枚数を書くだけで全部表示されます。

{
  "id": "2026-all-japan",
  "title": "2026全日本ジムカーナ",
  "date": "2026-11-20",
  "category": "Competition",
  "description": "3日間の大会の様子",
  "articleId": "2026-all-japan",
  "photoFolder": { "path": "images/gallery/2026-all-japan", "count": 42, "ext": "jpg" }
}

B. 1枚ずつ書く場合（キャプションを付けたいとき）

  "photos": [
    "images/gallery/2026-shinkan/start.jpg",
    { "src": "images/gallery/2026-shinkan/group.jpg", "caption": "集合写真", "author": "広報担当" }
  ]
  • category：下の表の英語のまま1つ。
  • cover：一覧に出す表紙（省略すると1枚目）。
  • articleId：関連するNews記事のid（任意）。記事側には "galleryId" を書くと相互にリンクされます。
  • A と B は同時に使えます（B の写真が先に並びます）。

7. サーバーへアップロードする（FTP）

  1. FTPソフト（FileZilla など）で、レンタルサーバーに接続する。接続情報はサーバー契約時の案内にあります。
  2. 公開用フォルダを開く（Xserver・お名前.comは public_html、さくらは www が目安。契約先の案内を確認）。
  3. 変更した data/*.json と、追加した画像だけをアップロードして上書きする。
  4. ブラウザで公開サイトを開き、再読み込み（Ctrl+F5 / スマホは更新）して確認する。
初回だけ、フォルダごと（index.html などの全ページ、css・js・data・images）をアップロードします。すべてのHTMLの https://YOUR-DOMAIN を公開URLに置換する作業は、引き継ぎ時に1回だけ必要です。

7.5 検索エンジン用ページを更新する（記事を追加したとき）

JSONを追加しただけでも記事は表示されます。さらに、Google検索に記事を1つずつ載せるため、アップロード前に次を行います。

  1. tools/build.bat をダブルクリック（Macやコマンドの場合は python tools/build.py）。
  2. 「✔ 完了しました」と出ればOK。「✖」が出たら表示どおりにJSONを直して再実行。「⚠」は画像が見つからないなどの注意です。
  3. news/・gallery/ フォルダ、sitemap.xml、data/_generated.json もアップロードする。
これで記事ごとに /news/記事ID.html・/gallery/イベントID.html のページ（タイトル・説明文入り）が作られ、sitemap.xml にも自動で追加されます。news/・gallery/ の中のファイルは手で編集しないでください。

8. SNS・連絡先を変える

SNSのURLとお問い合わせの宛先メールは js/main.js の最初にある SITE にまとまっています。ここだけは、引き継ぎ時にJavaScript担当（詳しい人）に頼んでください。
